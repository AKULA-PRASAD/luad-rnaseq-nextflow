Lung adenocarcinoma RNA-seq: tumour vs matched normal tissue

Engineering

Built to the standards of a production pipeline, not a one-off analysis.

Reproducible

  • Every tool pinned as a container and as a conda package
  • Versions used are recorded for each run
  • A from-scratch cluster rerun reproduced the first run: identical counts, the same 7,541 genes, every estimate within 10⁻⁶

Tested

  • 13 nf-test module and pipeline tests, with snapshot testing
  • 11 Python unit tests for count merging and strandedness detection
  • GitHub Actions CI on two Nextflow versions, with synthetic data that has planted effects checked against the truth

Runs on HPC

  • SLURM and Singularity profiles for Northeastern's Explorer cluster
  • Fixed a CPU-specific STAR container crash by using the cluster's STAR module
  • Fixed a JVM shared-memory crash in parallel FastQC
  • Avoided intermittent scheduler refusals with a single-allocation profile

Data provenance

An earlier version of this analysis used SRA runs that turned out to be ENCODE ChIP-seq of leukaemia and lymphoblastoid cell lines, not lung RNA-seq. The run metadata gave it away, and so did the output: few reads in genes and a BCR-ABL amplicon signal. Its conclusions were withdrawn, and the analysis was rebuilt from the GEO record.
